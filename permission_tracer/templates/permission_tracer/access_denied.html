Who can access it is configurable

Set ACCESS_CHECK in your settings.py, for example to allow anyone while DEBUG = True:

PERMISSION_TRACER = {
    "ACCESS_CHECK": "permission_tracer.conf.allow_in_debug",
}

It also accepts any function that takes the request and returns True or False, e.g. lambda request: request.user.is_superuser.

Avoid opening it to everyone on a shared or public server.
